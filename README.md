* **[Tikhonov-Regularized Huber Regression in RKHS](https://github.com/cepyhs/robust-huber-kernel-regression)**
  A statistical learning implementation combining Reproducing Kernel Hilbert Spaces (RBF kernel) with Huber loss and Tikhonov regularization to estimate non-linear trends under heavy-tailed noise, benchmarked against Kernel Ridge Regression ($L_2$-RKHS) and Linear OLS.
